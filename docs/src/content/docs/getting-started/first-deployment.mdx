## Deploy it

You need the .NET 10 SDK, Docker (or Podman) and [the `deployify` tool](/Deployify/getting-started/installation/).

<Steps>

1. Clone the repository and go to the AppHost:

   ```bash
   git clone https://github.com/lv3rmeulen/Deployify.git
   cd Deployify/samples/hello-aspire/HelloAspire.AppHost
   ```

2. Preview the deployment. Deployify runs the AppHost to get Aspire's manifest, writes the
   Compose files to `deployify-output/` and compares them with what's running:

   ```bash
   deployify plan
   ```

   Expect `2 to create`: `cache` and `api`. The Redis password Aspire asks for is generated once
   and saved in `deployify-parameters.json`, so every later deploy reuses it.

3. Build the API image into your local Docker:

   ```bash
   deployify publish
   ```

4. Deploy. `cache` goes first because `api` depends on it, and each wave has to be healthy
   before the next one starts:

   ```bash
   deployify apply --auto-approve
   ```

5. Call the API:

   ```bash
   curl http://localhost:8080/
   # {"message":"Hello from Aspire, deployed by Deployify","visits":1}
   ```

6. Look around, then clean up:

   ```bash
   deployify status                         # the rollout you just ran
   deployify destroy --auto-approve --volumes
   ```

</Steps>
