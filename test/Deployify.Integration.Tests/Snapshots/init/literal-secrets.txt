✗ These flags hold secrets and would be saved as plain text in deployify-state.json:
    --dashboard-token  → use --dashboard-token env:DEPLOYIFY_DASHBOARD_TOKEN
    --nomad-token  → use --nomad-token env:NOMAD_TOKEN, or leave it out to use NOMAD_TOKEN
    --nomad-registry-password  → use --nomad-registry-password env:DEPLOYIFY_REGISTRY_PASSWORD, or leave it out to use DEPLOYIFY_REGISTRY_PASSWORD
    --nc-nomad-token  → use --nc-nomad-token env:NOMAD_TOKEN, or leave it out to use NOMAD_TOKEN
    --nc-consul-token  → use --nc-consul-token env:CONSUL_HTTP_TOKEN, or leave it out to use CONSUL_HTTP_TOKEN
  Pass --allow-plaintext-secrets to store them anyway.
