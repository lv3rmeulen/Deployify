--project-path, -p : String = <cwd>
    Path to the Aspire AppHost .csproj or its directory.

    Disable interactive prompts; fail on missing required values.

    Environment name.

    Deployment target: nomad | kubernetes | helm | argocd | flux | ovhcloud | compose | awsecs | azurecontainerapps | nomadconsul | iis, or the ID of a plugin target.

    Container registry URL.

    Default image tag.

    Output folder for artifacts.

    Container runtime for publishing: docker (default) | podman.

    Target OS for container images (default: linux).

    Target CPU architecture for container images: x64 (default) | arm64 | arm.
